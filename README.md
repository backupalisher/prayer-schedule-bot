# Бот расписания намазов 🕌

Telegram бот для получения расписания намазов с автоматическими уведомлениями.

## Функции

- 📅 Независимый offline-расчёт времени намаза (библиотека `adhanpy`, параметры ДУМ РФ)
- 🤖 Telegram бот с командами:
  - `/start` - приветствие и список команд
  - `/today` - расписание на сегодня
  - `/next` - следующий намаз
  - `/pdf` - скачать PDF с расписанием на месяц
  - `/help` - помощь
- 🔔 Автоматические уведомления о времени намазов
- 📊 Генерация PDF расписания
- ⏰ Планировщик задач для ежемесячного пересчёта и уведомлений

## Параметры расчёта (ДУМ РФ / umma.ru)

По умолчанию используются координаты Москвы и:

| Параметр | Значение |
|----------|----------|
| Угол Фаджр | 16.0° |
| Угол Иша | 15.0° |
| Мазхаб (Аср) | Ханафи |
| Высокие широты | TWILIGHT_ANGLE |

Настройки можно переопределить в `.env`:

```env
PRAYER_LATITUDE=55.7558
PRAYER_LONGITUDE=37.6173
PRAYER_TIMEZONE=Europe/Moscow
PRAYER_USE_HANAFI=True
PRAYER_FAJR_ANGLE=16.0
PRAYER_ISHA_ANGLE=15.0
```

## Установка

Отредактируйте файл `.env`:
```env
BOT_TOKEN=your_bot_token_here
CHAT_ID=your_chat_id_here (опционально)
USE_TELEGRAM=True
```

## Получение токена бота

1. Откройте Telegram и найдите @BotFather
2. Создайте нового бота с помощью команды `/newbot`
3. Скопируйте полученный токен в `BOT_TOKEN`
4. Чтобы получить `CHAT_ID`, напишите боту @userinfobot

## Запуск

### Основной запуск:
```bash
run.sh $0 {start|stop|restart|status|logs|setup|install-service|enable-service|disable-service}
```
    setup            — создать .env и установить зависимости
    start            — запустить бота в фоне (nohup, без автоперезапуска)
    stop             — остановить бота
    restart          — перезапустить бота
    status           — проверить статус
    logs             — следить за логами (tail -f)
    
    install-service  — установить systemd-сервис (рекомендуется для сервера)
    enable-service   — включить автозапуск и автоперезапуск через systemd
    disable-service  — остановить и отключить systemd-сервис
```
