# Бот расписания намазов 🕌

Telegram-бот с независимым offline-расчётом времени намаза для любой точки мира.

## Функции

- 🌍 Персональный расчёт по геолокации пользователя (не привязан к Москве)
- 📅 Offline-алгоритм Adhan (`adhanpy`) + автоопределение часового пояса (`timezonefinder`)
- 🧭 Автовыбор метода расчёта:
  - **Мекка / Саудовская Аравия** → Umm al-Qura
  - **Россия / СНГ** → ДУМ РФ (Fajr 16°, Isha 15°, Ханафи)
  - **Египет** → Egyptian
  - **остальной мир** → Muslim World League
- 🔔 Индивидуальные уведомления по местному времени каждого пользователя
- 🤖 Команды:
  - `/start` — старт и запрос геолокации
  - `/location` — обновить геолокацию и пересчитать намазы
  - `/settings` — мазхаб Аср: Ханафи / Шафии
  - `/today` — расписание на сегодня
  - `/next` — следующий намаз
  - `/pdf` — PDF на месяц для вашей локации
  - `/help` — помощь

## Как это работает

1. Пользователь отправляет геолокацию.
2. Бот определяет часовой пояс и профиль расчёта.
3. Для пользователя считается и сохраняется персональное расписание.
4. Уведомления срабатывают отдельно для каждого пользователя в его локальном `HH:MM`.

## Установка

Отредактируйте `.env`:

```env
BOT_TOKEN=your_bot_token_here
CHAT_ID=your_chat_id_here
USE_TELEGRAM=True
```

## Запуск

```bash
./run.sh setup
./run.sh start
```

Полезные команды `run.sh`:
- `setup` — создать `.env` и установить зависимости
- `start` / `stop` / `restart` / `status` / `logs`
- `install-service` / `enable-service` / `disable-service`
